# Synthetic import fixtures

All files in this directory are small synthetic tutorial inputs, generated by
`scripts/generate_phase2_examples.py`. They are not manufacturer facts or laboratory
measurements. Use `--origin synthetic` for tabular/generic JSON examples; canonical
JSON already records synthetic lineage and needs no override.

- `device_switching.xlsx`: identity, switching and conduction worksheets; 48
  switching rows form exact current/temperature/voltage/gate-resistance tensors.
- `device_partial.csv`: two conduction points without temperature; partial is valid.
- `device_ambiguous.csv`: Loss1/Loss2 stay unresolved until `mapping_override.json`
  explicitly identifies quantities and units.
- `device_generic.json`: flat, named external tables using the same mapping pipeline.
- `device_canonical.json`: full valid V3 device generated from the workbook.

Production uploads must not be added here. The importer reads caller-provided files
transiently, never archives them, and never deletes the caller's own files.
